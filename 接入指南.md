# 图搜服务接入指南

> 面向外部业务系统的对接文档。照着本文复制示例即可跑通「上传图片 → 检索」全流程。

## 1. 服务信息

| 项 | 值 |
|---|---|
| 服务地址 | `http://192.168.255.141:5005` |
| API 基础路径 | `http://192.168.255.141:5005/api/v1` |
| 模型 | Chinese-CLIP RN50（图文同空间，1024 维） |
| 相似度 | 百分比字符串，如 `"95.50%"`（余弦相似度） |

**统一返回结构**：

```json
{ "status": true, "message": "success", "data": { ... } }
```

- `status=true` 成功，数据在 `data`；`status=false` 失败，原因在 `message`
- **图搜业务接口全部免鉴权**，外部服务可直接调用，无需 token
- 管理接口（用户/图库/日志/备份/压测）需管理员 token，接入方一般用不到

**连通性检查**：

```bash
curl http://192.168.255.141:5005/api/v1/health
```

## 2. 5 分钟快速接入

### 2.1 以图搜图（最常用）

```bash
curl -X POST 'http://192.168.255.141:5005/api/v1/tables/products/search/image' \
  -F 'image=@query.jpg' \
  -F 'topk=10'
```

或用图片链接：

```bash
curl -X POST 'http://192.168.255.141:5005/api/v1/tables/products/search/image' \
  -d 'image_url=https://example.com/img.jpg' \
  -d 'topk=10'
```

### 2.2 中文文本搜图

```bash
curl -X POST 'http://192.168.255.141:5005/api/v1/tables/products/search/text' \
  -d 'query_text=红色连衣裙' \
  -d 'topk=10'
```

### 2.3 响应示例

```json
{
  "status": true,
  "message": "success",
  "data": {
    "results": [
      { "imgId": "470590515983942590", "similarity": "95.50%", "commodityId": "SKU001", "customsParams": "" }
    ]
  }
}
```

> `products` 是图库名，换成你自己的图库。检索前需先把图片入库（见第 3 节）。

## 3. 图片入库

### 3.1 上传单张

支持本地文件或图片 URL，二选一。

```bash
# 本地文件
curl -X POST 'http://192.168.255.141:5005/api/v1/tables/products/images' \
  -F 'image=@test.jpg' \
  -F 'commodity_id=SKU001' \
  -F 'save_to_minio=true'

# 图片链接
curl -X POST 'http://192.168.255.141:5005/api/v1/tables/products/images' \
  -d 'image_url=https://example.com/a.jpg' \
  -d 'commodity_id=SKU001'
```

**表单参数**：

| 参数 | 必填 | 说明 |
|---|---|---|
| `image` | 二选一 | 图片文件 |
| `image_url` | 二选一 | 图片链接 |
| `commodity_id` | 否 | 商品 ID，建议传，便于业务对齐 |
| `customs_param` | 否 | 自定义参数，会随检索结果原样返回 |
| `save_to_minio` | 否 | 是否保存原图，默认 `true`；`false` 时只入库向量，取不到原图 |

**返回**：`{"status":true,"data":{"imgId":"470590515983942590"}}`

### 3.2 批量上传（推荐，异步）

```bash
curl -X POST 'http://192.168.255.141:5005/api/v1/tables/products/images/batch' \
  -H 'Content-Type: application/json' \
  -d '{
    "items": [
      { "image_url": "https://example.com/a.jpg", "commodity_id": "SKU001" },
      { "image_url": "https://example.com/b.jpg", "commodity_id": "SKU002" }
    ],
    "save_to_minio": true,
    "auto_id": true
  }'
```

立即返回：`{"status":true,"data":{"taskId":"a1b2c3...","total":2}}`

**查进度**：

```bash
curl 'http://192.168.255.141:5005/api/v1/tasks/{taskId}/progress'
```

**拿每张图的 imgId**（任务完成后）：

```bash
curl 'http://192.168.255.141:5005/api/v1/tasks/{taskId}/result?page=1&size=100'
```

返回：

```json
{
  "status": true,
  "data": {
    "total": 2, "page": 1, "size": 100,
    "items": [
      { "index": 0, "imgId": "470...", "commodityId": "SKU001", "rawUrl": "https://...", "customsParam": "" },
      { "index": 1, "imgId": "471...", "commodityId": "SKU002", "rawUrl": "https://...", "customsParam": "" }
    ]
  }
}
```

> `index` 对应你提交时 `items` 的序号，用它把 imgId 对齐回你的业务数据。映射清单存在磁盘分片里，数百万条也能分页拉取，不会把服务内存撑爆。

### 3.3 手动指定 ID 上传

需要先创建图库时设置 `auto_id=false`。

```bash
curl -X POST 'http://192.168.255.141:5005/api/v1/tables/products/images/manual-id' \
  -F 'milvus_id=10001' \
  -F 'image=@test.jpg'
```

## 4. Python 接入示例

依赖：`pip install requests`

```python
import requests

BASE = "http://192.168.255.141:5005/api/v1"
TABLE = "products"

def search_by_image(path: str, topk=10):
    with open(path, "rb") as f:
        resp = requests.post(
            f"{BASE}/tables/{TABLE}/search/image",
            files={"image": f}, data={"topk": topk}, timeout=30,
        )
    return resp.json()["data"]["results"]

def search_by_text(text: str, topk=10):
    resp = requests.post(
        f"{BASE}/tables/{TABLE}/search/text",
        data={"query_text": text, "topk": topk}, timeout=30,
    )
    return resp.json()["data"]["results"]

def upload(image_path: str, commodity_id: str):
    with open(image_path, "rb") as f:
        resp = requests.post(
            f"{BASE}/tables/{TABLE}/images",
            files={"image": f},
            data={"commodity_id": commodity_id, "save_to_minio": "true"},
            timeout=30,
        )
    return resp.json()["data"]["imgId"]

def batch_upload(urls: list[str]):
    items = [{"image_url": u, "commodity_id": f"SKU{i}"} for i, u in enumerate(urls)]
    resp = requests.post(
        f"{BASE}/tables/{TABLE}/images/batch",
        json={"items": items, "save_to_minio": True, "auto_id": True},
        timeout=60,
    )
    task_id = resp.json()["data"]["taskId"]
    # 轮询进度
    while True:
        p = requests.get(f"{BASE}/tasks/{task_id}/progress").json()["data"]
        if p["status"] in ("done", "failed"):
            break
        import time; time.sleep(2)
    # 拿映射
    result = requests.get(f"{BASE}/tasks/{task_id}/result", params={"page": 1, "size": 100}).json()["data"]
    return result["items"]

if __name__ == "__main__":
    for r in search_by_text("红色连衣裙"):
        print(r["imgId"], r["similarity"], r.get("commodityId"))
```

## 5. Java 接入示例

Maven 依赖：

```xml
<dependency>
  <groupId>com.squareup.okhttp3</groupId>
  <artifactId>okhttp</artifactId>
  <version>4.12.0</version>
</dependency>
```

```java
import okhttp3.*;
import java.io.File;
import java.util.concurrent.TimeUnit;

public class ImageSearchClient {
    private static final String BASE = "http://192.168.255.141:5005/api/v1";
    private static final String TABLE = "products";
    private final OkHttpClient client = new OkHttpClient.Builder()
            .connectTimeout(30, TimeUnit.SECONDS).build();

    /** 以图搜图 */
    public String searchByImage(File image, int topk) throws Exception {
        RequestBody body = new MultipartBody.Builder().setType(MultipartBody.FORM)
                .addFormDataPart("image", image.getName(),
                        RequestBody.create(MediaType.parse("image/jpeg"), image))
                .addFormDataPart("topk", String.valueOf(topk))
                .build();
        Request req = new Request.Builder()
                .url(BASE + "/tables/" + TABLE + "/search/image").post(body).build();
        try (Response resp = client.newCall(req).execute()) {
            return resp.body().string();
        }
    }

    /** 中文文本搜图 */
    public String searchByText(String query, int topk) throws Exception {
        RequestBody body = new FormBody.Builder()
                .add("query_text", query).add("topk", String.valueOf(topk)).build();
        Request req = new Request.Builder()
                .url(BASE + "/tables/" + TABLE + "/search/text").post(body).build();
        try (Response resp = client.newCall(req).execute()) {
            return resp.body().string();
        }
    }

    /** 上传单张 */
    public String upload(File image, String commodityId) throws Exception {
        RequestBody body = new MultipartBody.Builder().setType(MultipartBody.FORM)
                .addFormDataPart("image", image.getName(),
                        RequestBody.create(MediaType.parse("image/jpeg"), image))
                .addFormDataPart("commodity_id", commodityId)
                .addFormDataPart("save_to_minio", "true")
                .build();
        Request req = new Request.Builder()
                .url(BASE + "/tables/" + TABLE + "/images").post(body).build();
        try (Response resp = client.newCall(req).execute()) {
            return resp.body().string();
        }
    }

    public static void main(String[] args) throws Exception {
        ImageSearchClient c = new ImageSearchClient();
        System.out.println(c.searchByText("红色连衣裙", 10));
    }
}
```

## 6. 接口速查表

以下均为**免鉴权**业务接口，前缀 `/api/v1`：

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/health` | 健康检查 |
| GET | `/tables` | 图库列表 |
| GET | `/tables/{table}/stats` | 图片数量 |
| POST | `/tables/{table}/images` | 上传单张 |
| POST | `/tables/{table}/images/manual-id` | 手动 ID 上传 |
| POST | `/tables/{table}/images/batch` | 批量上传（异步） |
| GET | `/tasks/{taskId}/progress` | 批量任务进度 |
| GET | `/tasks/{taskId}/result` | 批量任务 imgId 映射 |
| POST | `/tables/{table}/search/image` | 以图搜图 |
| POST | `/tables/{table}/search/text` | 中文文本搜图 |
| POST | `/tables/{table}/search/image/lite` | 以图搜图（轻量，只返回 imgId+similarity） |
| POST | `/tables/{table}/search/text/lite` | 文本搜图（轻量） |
| GET | `/tables/{table}/images/{id}/content` | 获取原图（未落 MinIO 不可用） |
| GET | `/tables/{table}/images` | 分页列表 |
| DELETE | `/tables/{table}/images/{id}` | 删除单张 |

**轻量版接口**（`/search/*/lite`）只返回 `imgId` 和 `similarity`、完全不查 MySQL，适合外部服务高频调用，延迟更低。

## 7. 常见问题

**Q：检索结果为空？**
先确认图库名正确、图片已入库成功。刚上传的图片有最长约 2 秒的不可检索窗口（延迟 flush），稍后重试即可。

**Q：`save_to_minio=false` 的图片能搜到吗？**
能搜到，但调「获取原图」接口会失败——因为只存了向量没存原图，属正常现象。

**Q：批量上传的 imgId 怎么跟我的数据对上？**
用 `/tasks/{taskId}/result` 返回的 `index` 字段对齐你提交 `items` 时的顺序；或提交时带 `commodity_id`，结果里会原样返回。

**Q：中文搜图需要翻译吗？**
不需要。Chinese-CLIP 原生支持中文，直接传中文文本即可。

**Q：上传报「映射记录写入失败」？**
多为 `(raw_url, commodity_id)` 重复触发唯一键冲突。换用不同的 commodity_id 或先删除旧记录。具体错误会写在服务端审计日志的 `error` 字段。

**Q：需要 token 吗？**
上面列出的业务接口都不需要。只有管理接口（创建/删除图库、用户管理、日志、备份、压测）需要管理员 token，接入方一般用不到。
